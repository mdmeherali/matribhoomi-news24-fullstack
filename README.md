# Matribhoomi News24 - Fullstack Project

**Matribhoomi News24** একটি আধুনিক ফুলস্ট্যাক নিউজ পোর্টাল ওয়েবসাইট। এখানে ব্যবহারকারীরা সর্বশেষ খবর পড়তে পারবেন এবং অ্যাডমিন প্যানেল থেকে খবর নিয়ন্ত্রণ করা যাবে।

## 🚀 টেকনোলজি স্ট্যাক (Tech Stack)

- **Frontend:** React.js / Next.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB / MySQL

## 🛠️ প্রজেক্টটি আপনার কম্পিউটারে রান করার নিয়ম (Installation Guide)

### ১. প্রজেক্টটি ক্লোন করুন
```bash
git clone https://github.com
cd matribhoomi-news24-fullstack
```

### ২. ব্যাকএন্ড সেটআপ (Backend Setup)
```bash
cd backend
npm install
npm start
```

### ৩. ফ্রন্টএন্ড সেটআপ (Frontend Setup)
```bash
cd ../frontend
npm install
npm start
```
